About HL7Forge (dev)

      
    

    

      
HL7Forge is a private, in-browser viewer for HL7 v2 messages. Paste a message, open a file, or drop one in, and it breaks the message into segments, fields, repetitions, components, and sub-components, each labelled with its field name and data type.

      
    
        
  • Coded values are decoded (F → Female, AE → Application Error) and timestamps are shown in a readable form.
    • 
        
  • Batches, MLLP framing, and custom delimiters are handled, and the cursor bar shows the path of the field you're on, e.g. OBX[3]-5.1.
    • 
        
  • Save messages for the session and switch between them with Alt↑↓ or CtrlK.
    • 
      

      
Everything runs in this browser tab. There is no server, and the page's Content-Security-Policy blocks every network request, so your messages never leave this computer.
